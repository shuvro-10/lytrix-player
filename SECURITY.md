# Security Policy

## Supported Versions

Only the latest release of Lytrix Player receives security updates and bug fixes.

| Version | Supported |
| ------- | --------- |
| 1.0.x (Latest) | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit within Lytrix Player, please **do not** open a public issue.

Please report it privately via:
- **Telegram Support:** [@lytrixsupport](https://t.me/lytrixsupport)
- **GitHub Security:** Open a private advisory report directly under the "Security" tab of this repository.

### Please include in your report:
1. Description of the vulnerability.
2. Steps to reproduce the issue (or a proof-of-concept).
3. The affected app version and Android OS version.

We appreciate your effort in responsibly disclosing vulnerabilities and will respond as quickly as possible.
